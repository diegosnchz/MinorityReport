# Using dataEngineer Data in feature/gat-model

## Quick Start Guide 🚀

### Español 🇪🇸

**¿Cómo usar los datos de dataEngineer en feature/gat-model?**

#### Opción 1: Exportar datos de Neo4j (Recomendado)
```bash
# 1. Asegúrate de que Neo4j esté corriendo con los datos generados
#    (debe estar ejecutado el script de dataEngineer/init_city_graph.py)

# 2. Exporta los datos

# 3. Entrena el modelo GAT
python examples/train_gat_with_dataengineer_data.py --data data/ --epochs 100
```

#### Opción 2: Conexión directa a Neo4j
```bash
# Entrena directamente desde Neo4j
python examples/train_gat_with_dataengineer_data.py --live --epochs 100
```

#### Opción 3: Usar en tu propio código
```python
from src.utils.data_loader import load_exported_data

# Cargar datos exportados
data = load_exported_data("data/")

# Ahora puedes usar 'data' para entrenar tu modelo GAT
print(f"Nodos: {data.num_nodes}")
print(f"Edges: {data.num_edges}")
print(f"Features: {data.num_features}")
```

## Data Structure

### From dataEngineer Branch

The dataEngineer branch generates a city simulation with:

**Citizens (Nodes):**
- 1000 citizens with features:
  - Age (normalized)
  - Job (one-hot encoded)
  - Criminal degree (# of criminal friends)
  - Risk seed (target label, 0-1)

**Relationships (Edges):**
- Social network (KNOWS relationships)
- Crime history (COMMITTED_CRIME)
- Location visits (VISITED)

**Locations:**
- 50 locations with spatial coordinates
- Environmental risk factors

### PyTorch Geometric Format

When loaded, the data becomes:
```python
data.x        # [num_nodes, num_features] - Node features
data.edge_index  # [2, num_edges] - Graph connectivity
data.y        # [num_nodes, 1] - Risk labels (0-1)
```

## Installation

### Dependencies

```bash
# Core dependencies
pip install torch torch-geometric neo4j pandas

# For GPU support (optional)
pip install torch-geometric --extra-index-url https://pytorch-geometric.com/whl/torch-2.0.0+cu118.html
```

### Neo4j Setup (for live connection)

If using direct Neo4j connection:

1. Make sure Neo4j is running (default: `bolt://localhost:7687`)
2. Set up credentials using environment variables (recommended):
   ```bash
   export NEO4J_URI="bolt://localhost:7687"
   export NEO4J_USER="neo4j"
   export NEO4J_PASSWORD="your_password_here"
   ```
3. Or pass credentials as arguments to the scripts
4. Database should contain data generated by dataEngineer scripts

## Examples

### Export Data
```bash
# Export to both CSV and PyTorch formats
python scripts/export_data_from_neo4j.py --output data/ --format both

# Export only PyTorch format (faster loading)
python scripts/export_data_from_neo4j.py --output data/ --format pytorch
```

### Train GAT Model
```bash
# Basic training
python examples/train_gat_with_dataengineer_data.py --data data/

# Custom hyperparameters
python examples/train_gat_with_dataengineer_data.py \
    --data data/ \
    --epochs 200 \
    --lr 0.01 \
    --hidden 128 \
    --heads 8

# Save trained model
python examples/train_gat_with_dataengineer_data.py \
    --data data/ \
    --epochs 100 \
    --save models/gat_model.pt
```

### Load and Inspect Data
```bash
# View data statistics
python src/utils/data_loader.py data/
```

## Troubleshooting

### "No data found in Neo4j"
- Make sure Neo4j is running
- Run the city generation script from dataEngineer branch
- Check Neo4j connection credentials

### "Failed to load data"
- Run export script first: `python scripts/export_data_from_neo4j.py`
- Check that data/ directory exists and contains files

### "Import error: No module named 'neo4j'"
- Install dependencies: `pip install neo4j torch torch-geometric pandas`
