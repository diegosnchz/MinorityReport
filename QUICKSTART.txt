## 📦 Instalación Manual (Si Prefieres Paso a Paso)

```powershell
# Crear venv
python -m venv venv311
.\venv311\Scripts\Activate.ps1

# Instalar
pip install -r config/requirements.txt
pip install -r config/requirements_cuda.txt

# Ejecutar
docker-compose down -v
docker-compose up neo4j -d
Start-Sleep -Seconds 30
python scripts/seed_neo4j.py --citizens 200
python scripts/train_with_neo4j.py --model both --epochs 100
```

## ⚡ Comandos Principales

```powershell
# Generar datos (200 ciudadanos)
python scripts/seed_neo4j.py --citizens 200

# Entrenar crime prediction (50 épocas)
python scripts/train_with_neo4j.py --model crime --epochs 50

# Entrenar escape routes (50 épocas)
python scripts/train_with_neo4j.py --model escape --epochs 50

# Entrenar ambos
python scripts/train_with_neo4j.py --model both --epochs 100

# Entrenar en CPU
python scripts/train_with_neo4j.py --model both --device cpu

# Ver GPU
nvidia-smi

# Activar venv
.\venv311\Scripts\Activate.ps1

# Docker
docker-compose up neo4j -d
docker-compose down
docker-compose logs neo4j
```

## 🐛 Errores Comunes

| Error | Solución |
|-------|----------|
| Docker not running | Abrir Docker Desktop |
| Neo4j connection failed | `docker-compose restart neo4j` + esperar 30s |
| Python not found | Usar `python3` o verificar PATH |
| CUDA out of memory | `--device cpu` o reducir `--citizens` |
| numpy error | `pip install "numpy<2.0"` |
| Module not found | `.\venv311\Scripts\Activate.ps1` |

**Ver más**: TROUBLESHOOTING.md
